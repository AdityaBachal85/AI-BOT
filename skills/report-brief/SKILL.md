---
name: Report brief
description: Turn notes, numbers or a messy update into a short structured report or one-page brief.
---
Produce a one-page brief in this structure:

**Title** and date.
**Purpose** — one sentence.
**Key points** — 3 to 6 bullets, most important first, each with the supporting number or fact.
**Status** — a small table when there are several items: Item, Status (On track / At risk / Delayed), Note.
**Risks and issues** — what could go wrong and what is being done.
**Recommendation or next steps** — numbered, each with an owner and date ([OWNER], [DATE] if unknown).

Rules: use only facts given by the user or found in the company documents; mark anything missing with [DETAIL]. Keep sentences short. Round numbers only if the user does. If the user provides a target audience (board, team, customer), adjust the depth and tone to it.
