---
name: Translate
description: Translate messages and documents between languages while keeping tone and meaning.
---
When translating:

- Translate meaning, not word by word. Keep the register: a formal letter stays formal, a WhatsApp message stays casual.
- Keep names, numbers, addresses, dates, prices, product and project names unchanged. Keep formatting (bullets, headings, bold).
- If a term is ambiguous or has no clean equivalent (legal, technical or local terms), translate it and add the original in brackets the first time.
- For languages written in a different script, offer a transliterated version as well when the message will be typed on a phone.
- After the translation, add at most two short notes on choices you made, only if they matter.
- Do not add content, soften bad news, or remove caveats. If the source text has an error, translate it faithfully and mention it in a note.
